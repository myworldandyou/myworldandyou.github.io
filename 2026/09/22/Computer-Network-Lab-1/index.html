实验一：静态网页制作

发表于2026-09-22|更新于2026-09-22|计算机网络实验
|浏览量:

本实验完成一个内容完整、能够公开访问的静态网页。你需要在网页中使用图片和超链接，发布一篇新博客，并通过浏览器开发者工具确认网页使用的 HTTP 协议版本。

实验任务

完成以下内容：

  1. 制作一个主题明确、内容充实的网页。
  2. 发布一篇新的博客文章。
  3. 检查网页使用的 HTTP 协议版本。
  4. 在网页中加入至少三个超链接，并包含图片。

网页主题可以选择自我介绍、家乡介绍、学校介绍、生活分享或研究分享。页面框架可以自行决定，不要求必须使用 Hexo。

HTML 与网页结构

HTML 是超文本标记语言。浏览器读取 HTML 标签，并将文字、图片、链接等内容显示为网页。一个最小页面包含文档声明、头部信息和页面主体：

网站通常由多个文件共同组成：

常用 HTML 标签

标签 作用 示例
<h1> 至 <h6> 标题 <h1>实验一</h1>
<p> 段落 <p>正文</p>
<a> 超链接 <a href="https://www.ustc.edu.cn/">中国科学技术大学</a>
<img> 图片 <img src="images/photo.jpg" alt="图片说明">
<ul>、<ol> 无序列表、有序列表 <li>列表项目</li>
<div> 内容分区 <div class="section">...</div>
<table> 表格 与 <tr>、th、td 配合使用

图片必须填写有意义的 alt 文本。外部链接如需在新标签页打开，可以使用 target="_blank"，并同时加入 rel="noopener"。

HTTP 版本观察

HTTP 是浏览器与服务器交换网页资源所使用的应用层协议。常见版本包括：

版本 主要特点
HTTP/1.0 默认使用短连接，每次请求后通常关闭 TCP 连接
HTTP/1.1 默认持久连接，支持 Host、缓存控制、分块传输与范围请求
HTTP/2 二进制分帧、多路复用、HPACK 头部压缩
HTTP/3 基于 QUIC 与 UDP，支持连接迁移，减少队头阻塞影响

检查方法：

  1. 打开已经发布的网页。
  2. 按 F12 打开浏览器开发者工具。
  3. 选择“网络”或 “Network”面板。
  4. 刷新网页。
  5. 在表头区域启用“协议”或 “Protocol”列。
  6. 查看主文档请求对应的协议值。

常见显示值：http/1.1 表示 HTTP/1.1，h2 表示 HTTP/2，h3 表示 HTTP/3。记录时应以自己网页的实际检查结果为准。

使用 localhost 预览时观察到的协议不能代表 GitHub Pages 的公网访问协议。请对发布后的网址进行检查。

提交前检查

  • 网页主题明确，内容完整。
  • 已发布一篇新的博客文章。
  • 页面至少包含三个有效的超链接。
  • 页面包含图片，且图片能够正常加载。
  • 页面在电脑和手机宽度下均可阅读。
  • 已记录公网网页使用的 HTTP 协议版本。
  • 所有链接均已实际点击检查。
